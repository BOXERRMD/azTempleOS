# azTempleOS

**<ins>azTempleOS</ins>** is a fork of the x86-64 **TempleOS operating system** made by *Terry-A Davis*.

At the begining, I have made this fork to add an AZERTY keyboard mapping support *(I'm french 🙂)*.
But after a lot of time, I have add more and more things like a dynamic change keyboard mapping (and yes, you can made your own mapping),
a shell path completion like Linux (ALT-TAB to complete a path), a font manager to make your own font and load it at every start.

Actualy, I have done the shell path completion and I'm working on a **COM communication protocol** to, first, send messages to TempleOS from the OS host.
Secondary, execute command on TempleOS, and finally transmit files from TempleOS to the os host and host to TempleOS. (For updates it will be amazing 🤟)


You can find the .ISO **[here](https://github.com/BOXERRMD/azTempleOS/tree/main/azTempleOS_source_code/azTempleOS)**
